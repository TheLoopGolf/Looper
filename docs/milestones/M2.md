# M2 — Core editing: report

## What was built

**Core (packages/core)** — all editing is commands, so every tool below is also available to agents and plugins.

| Area | Commands |
| --- | --- |
| Selections | `selection.rect`, `.ellipse`, `.polygon` (lasso / polygonal lasso), `.magicWand`, `.colorRange`, `.all`, `.deselect`, `.invert`, `.feather`, `.expand`, `.contract`, `.fromLayer`, `.save` / `.load` (channels), `channel.delete`. Modes: replace / add / subtract / intersect; anti-aliased edges; exact Euclidean expand/contract. |
| Painting | `paint.stroke` (brush and eraser; pressure → size/opacity; hardness, flow, spacing; targets pixels, layer mask, or the selection for quick mask), `pixels.fill`, `pixels.clear`, `pixels.floodFill` (paint bucket), `pixels.gradient` (linear, radial, angle, reflected, diamond). All respect the selection. |
| Masks | `layer.addMask` (reveal all / hide all / from selection), `.deleteMask`, `.applyMask`, `.setMaskEnabled`, `.invertMask`, `.setMaskDensity`. Rendered per pixel on CPU, WebGL2 and WebGPU. |
| Adjustments (12) | Brightness/Contrast, Levels, Curves, Exposure, Hue/Saturation (incl. colorize), Vibrance, Color Balance, Black & White, Photo Filter, Invert, Posterize, Threshold — as non-destructive adjustment layers (`layer.createAdjustment`, `layer.setAdjustment`; opacity, blend mode and mask apply) and as direct ops (`adjust.apply`). |
| Filters (7) | Gaussian Blur, Motion Blur, Unsharp Mask, High Pass, Add Noise (seeded), Pixelate, Emboss — `filter.*`, selection-limited. |
| Vector & text | `layer.createShape` / `.updateShape` (rect with radius, ellipse, polygon/star, line, pen path; fill + stroke), `layer.createText` / `.updateText` (font, size, weight, italic, color, alignment, line height, tracking, paragraph width), `layer.rasterize`. |
| Transform & canvas | `layer.translate`, `layer.transform` (affine; pixels bilinear, vectors exact), `layer.flip`, `document.crop` (with straighten angle), `document.cropToSelection`, `document.resizeCanvas` (anchor), `document.resizeImage`. |
| Layers | `layer.mergeDown`, `layer.flatten` (in addition to M1). |

The brush engine is deterministic and shared by the live preview and the committed command, so the
pixels you see while painting are exactly what history records.

**UI (packages/ui)**

- Tools: Move (+ Free Transform with scale/rotate handles, Shift for uniform/15° snaps), Rectangular / Elliptical
  Marquee, Lasso, Polygonal Lasso, Magic Wand, Crop (aspect presets incl. 1:1, 4:5, 16:9, 9:16; straighten),
  Eyedropper, Brush, Eraser, Paint Bucket, Gradient, Text (in-place editor), Shape (rect, ellipse, polygon,
  line, pen), Hand, Zoom; foreground/background colors; Quick Mask.
- Canvas overlays: marching ants, quick-mask tint, marquee/lasso guides, crop box with rule-of-thirds,
  transform box, brush cursor.
- Options bar per tool; Properties panel (adjustment settings incl. a curve editor, text and shape settings,
  mask controls); mask chip in the Layers panel to paint on a mask.
- Menus: Image › Adjustments, Layer › New Adjustment Layer / Layer Mask / Rasterize / Merge Down / Flatten,
  Select (Color Range, Modify, Save/Load Selection, Quick Mask), Filter. Dialogs are generated from command
  schemas and preview live.
- Export dialog: PNG / JPEG / WebP / AVIF (when the browser can encode it), quality, scale, metadata stripping
  (default; otherwise only a Software tag), sRGB, and "Export layers…" (one PNG per layer in a zip).
- Autosave to IndexedDB a moment after edits stop; unsaved documents left behind by a crash are offered on
  the next start (Restore / Discard / Decide later).

## How to run

Same as M1: `pnpm dev`, `pnpm test`, `pnpm test:e2e`, `pnpm bench`.

## Test results (headless Chromium, SwiftShader software GPU)

| Suite | Result |
| --- | --- |
| Vitest | 131 / 131 passed |
| CPU golden images | 26 blend modes, 3 group scenes, 12 adjustment layers (+ 1 with a blend mode), layer/group masks, 7 filters, brush strokes, shapes — all exact vs stored goldens |
| GPU vs CPU (WebGPU and WebGL2) | blend modes, groups, 14 adjustment scenes, masks — **max diff 1 LSB** on both backends |
| Playwright | 26 / 26 passed (M1 flows + every M2 tool, dialogs, export, autosave recovery) |

**M2 acceptance — golden-image tests pass for all blend modes, adjustments and filters (≤ 1 LSB at 8-bit): met.**
Filters run on the CPU only (one implementation), so their goldens pin determinism rather than compare backends.

### Brush latency (target < 16 ms)

`pnpm bench` — work per pointer event (stamping, applying to touched tiles, preview document, renderer
recomposite + draw) on a 6000×4000 document with 20 layers:

| Backend | p50 | p95 | max |
| --- | --- | --- | --- |
| WebGPU | 3.5 ms | 10.8 ms | 21 ms |
| WebGL2 | 3.9 ms | 11.2 ms | 18 ms |

Spikes happen when a stroke enters new tiles and all 20 layers must be recomposited for them on the software
GPU; real hardware should do better, but this still needs confirming there.

## Known gaps

- Clipping masks, vector masks and mask feather are not implemented (mask `feather` is stored but ignored).
- Healing, clone stamp, dodge/burn, smudge, blur/sharpen brushes and custom brush tips are M3.
- Filters and adjustments run in TypeScript on the main thread; the Rust/WASM + Web Worker port is planned for
  the M3 performance pass (large blurs block the UI for a moment).
- Moving or transforming a layer clips content outside the canvas (layers are canvas-sized).
- Text uses system fonts through the browser's font engine; text pixels are not golden-tested (platform fonts differ).
- Free transform has no perspective/skew handles yet; crop straighten draws the rotated box but has no
  rotate-by-dragging gesture.
- Color profiles: export is always sRGB; Display P3 needs color management (later).
- Desktop shell is unchanged from M1 and still not compiled in this environment.
